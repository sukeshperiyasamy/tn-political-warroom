# tn-political-warroom

Tamil Nadu Political War Room & Intelligence Monitoring Platform.

## Overview

This repository hosts the political war room intelligence tracking, analytics, and workflow systems for Tamil Nadu political monitoring.

## Development Setup

- **Language / Runtime**: Node.js v22+, Python 3.13+
- **Assistant & Skill Configuration**: Claude Code project environment configured in `.claude/` and `CLAUDE.md`.
- **E2E Testing**: Playwright (`npx playwright test`).
- **Knowledge Graph**: Graphify AST extraction (`graphify`).
